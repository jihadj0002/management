Finish connecting Firebase

The dashboard is built, but it still needs the web app credentials from your Firebase project. This takes about two minutes.

  1. 1

    Register a web app

    Open Project settings → Your apps, click the Web icon, nickname it management-dashboard, and copy the firebaseConfig values.

  2. 2

    Paste the config

    Replace the placeholders in public/firebase-config.js with your apiKey, messagingSenderId, and appId.

  3. 3

    Enable Email/password

    In Authentication → Sign-in method, enable the Email/Password provider.

  4. 4

    Create Firestore and deploy rules

    Create a Firestore database, then deploy the included security rules with npx firebase-tools deploy --only firestore:rules.

Your API key is safe to ship. Access is controlled by the Firestore security rules in firestore.rules.
